# Manual screen-reader checklist

Automation does not complete this checklist. Record operating system, browser, assistive technology,
version, date, tester, and observations for each completed run.

## Required scenarios

- [ ] Catalog landmarks, headings, skip link, and controls have useful names and order.
- [ ] Dialog opening announces title/context; Tab remains modal; Escape and Close return focus.
- [ ] Tabs announce selected state, position, and panel change without duplicate content.
- [ ] Combobox announces expansion, result count/active option, selection, empty state, and collapse.
- [ ] Text-field help and error content are understandable without visual position.
- [ ] New toast content is announced once and dismissal remains discoverable.
- [ ] Table caption and headers are announced for data cells.
- [ ] Dark theme, compact density, 200% zoom, RTL, and forced colors preserve operability.
