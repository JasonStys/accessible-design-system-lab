# File catalog

## Root configuration

- `package.json` — public package contract and all repeatable scripts.
- `package-lock.json` — exact dependency graph generated by npm.
- `index.html` — semantic React catalog entry.
- `vanilla.html` — standalone progressive-enhancement entry.
- `vite.config.ts` — demo build and Vitest coverage.
- `vite.lib.config.ts` — externalized React library build.
- `playwright.config.ts` — desktop/mobile browser matrix.
- `eslint.config.js` — strict TypeScript, React, browser, test, and Node rules.
- `tsconfig*.json` — application, tooling, and declaration contracts.

## Source

- `src/index.ts` — explicit package exports and reusable styles.
- `src/App.tsx`, `src/main.tsx` — integrated portfolio catalog and bootstrap.
- `src/components/` — seven public components plus focused tests.
- `src/styles/tokens.css` — semantic design tokens and environmental modes.
- `src/styles/components.css` — package component styles.
- `src/styles/demo.css` — presentation-only catalog layout.
- `src/stories/DesignSystem.stories.tsx` — isolated Storybook states.
- `src/vanilla/dialog-demo.js` — framework-independent dialog enhancement.
- `src/test/setup.ts` — semantic assertions and jsdom dialog test doubles.

## Verification and automation

- `tests/e2e/design-system.spec.ts` — keyboard, axe, responsive, RTL, motion, and vanilla scenarios.
- `scripts/clean.mjs` — allowlisted generated-output cleanup.
- `scripts/check-bundle.mjs` — gzip budget and JSON evidence.
- `scripts/package-smoke.mjs` — packed clean-consumer verification.
- `scripts/generate-code-index.mjs` — declaration line index.
- `scripts/validate-repository.mjs` — documentation, link, header, and content policy.
- `scripts/verify.sh` — Unix verification entry.
- `.storybook/` — React/Vite, docs, and a11y configuration.
- `.github/workflows/` — CI, dependency review, and CodeQL.

## Documentation

`docs/` contains architecture, API, accessibility, tokens, complexity, testing, operations, research,
an ADR, generated code locations, and evidence reports. README links to each reader-oriented entry.
